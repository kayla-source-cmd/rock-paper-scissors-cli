# Rock Paper Scissors CLI

A beginner-friendly Python command-line game where players compete against the computer in Rock, Paper, Scissors.

## Features
- Player chooses rock, paper, or scissors.
- Computer makes a random choice.
- Automatically determines the winner.
- Tracks player and computer scores.
- Supports multiple rounds.
- Allows players to quit the game.

## Technologies
- Python 3
- Random module
- Conditional statements
- While loops

## How to Run

```bash
python3 rock_paper_scissors.py
```
